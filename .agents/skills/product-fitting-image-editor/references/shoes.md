# 신발 교체 전용 프롬프트

대괄호를 실제 제품 정보로 바꿔 사용한다.

```text
Use case: identity-preserve, precise-object-edit
Asset type: 온라인 쇼핑몰 상세페이지용 피팅 사진

입력 이미지:
- 이미지 1: 수정 대상인 원본 피팅 사진
- 이미지 2~N: 교체할 신발 [제품명/SKU]의 [정면/측면/후면/위쪽/밑창/디테일] 참고사진

주요 요청:
이미지 1에서 모델이 착용한 기존 신발만 이미지 2~N의 [제품명] [색상] 신발로 교체한다. 좌우 한 쌍을 모델이 실제로 착용한 것처럼 자연스럽고 정확하게 표현한다.

변경 허용 영역:
양쪽 신발, 신발에 실제로 가려지는 발의 경계, 신발과 바닥이 만나는 접지 그림자만 최소한으로 수정한다. 바지나 양말과 겹치는 경계는 필요한 범위에서만 조정한다.

제품 재현 기준:
참고사진의 앞코, 발볼, 뒤축, 갑피, 스트랩 또는 끈의 개수와 교차 방향, 스티치, 여밈, 인솔, 미드솔, 아웃솔, 굽의 높이와 형태를 유지한다. [소재]의 질감, [색상], 밑창 두께와 제품 고유 비율을 정확히 표현한다. 좌우 신발은 같은 디자인으로 만들되 원본의 발 방향과 원근을 따른다.

반드시 유지:
모델의 체형, 다리 길이, 종아리와 발목 두께, 발 크기, 발의 방향과 간격, 자세와 체중 중심을 유지한다. 상의, 하의, 가방, 액세서리와 배경은 원본 그대로 유지한다. 카메라 시점, 크롭, 조명, 그림자 방향, 색온도, 초점과 사진 질감을 유지한다.

가림과 물리 표현:
발이 인솔 위에 실제로 놓이고 갑피·스트랩·끈이 발의 형태를 따라 자연스럽게 접촉하게 한다. 발가락과 뒤꿈치는 신발 구조에 맞는 위치에 있어야 한다. 밑창은 바닥에 자연스럽게 닿아야 하며 원본 광원과 일치하는 접지 그림자를 만든다. 하의 밑단과 신발의 앞뒤 가림 관계를 유지한다.

금지:
발 크기, 발목 위치 또는 다리 자세를 바꾸지 않는다. 발, 발가락, 신발, 끈과 스트랩을 추가·삭제·복제하지 않는다. 좌우 신발 디자인을 다르게 만들지 않는다. 신발이 바닥에 뜨거나 발이 신발을 관통하게 만들지 않는다. 임의의 로고와 문자를 추가하지 않고 참고사진의 배경과 워터마크를 옮기지 않는다.
```
