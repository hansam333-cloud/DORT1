# 상의 교체 전용 프롬프트

대괄호를 실제 제품 정보로 바꿔 사용한다.

```text
Use case: identity-preserve, precise-object-edit
Asset type: 온라인 쇼핑몰 상세페이지용 피팅 사진

입력 이미지:
- 이미지 1: 수정 대상인 원본 피팅 사진
- 이미지 2~N: 교체할 상의 [제품명/SKU]의 [정면/측면/후면/디테일] 참고사진

주요 요청:
이미지 1에서 모델이 착용한 기존 상의만 이미지 2~N의 [제품명] [색상] 상의로 교체한다. 결과는 실제 촬영한 것처럼 사실적이어야 하며, 제품 정보가 정확하게 보여야 한다.

변경 허용 영역:
상의 본체와 상의가 닿는 목, 어깨, 겨드랑이, 팔, 손목, 허리 및 다른 의상과 겹치는 경계만 최소한으로 수정한다. 제품 착용에 필요한 가림, 눌림, 당김, 주름과 접촉 그림자만 조정한다.

제품 재현 기준:
참고사진의 네크라인, 어깨선, 암홀, 소매 형태와 길이, 가슴·허리 여유, 총장, 밑단, 절개, 봉제, 여밈, 포켓, 부자재와 로고 위치를 유지한다. [소재]의 조직, 두께, 광택, 탄성, 색상과 드레이프를 정확히 표현한다. 제품 고유의 [핏]과 실루엣을 유지하되 모델의 기존 신체 비율에 자연스럽게 맞춘다.

반드시 유지:
모델의 동일성, 얼굴, 피부색, 헤어, 체형, 어깨 너비, 가슴과 허리 비율, 팔 길이와 두께, 자세를 유지한다. 하의, 신발, 가방, 액세서리와 배경은 원본 그대로 유지한다. 카메라 시점, 크롭, 조명, 그림자, 색온도, 초점과 사진 질감을 유지한다.

가림과 물리 표현:
상의와 피부, 상의와 하의, 상의와 가방 또는 액세서리의 앞뒤 관계를 원본 포즈에 맞게 표현한다. 원단 두께와 중력에 맞는 주름만 만들고, 신체를 관통하거나 공중에 뜬 옷을 만들지 않는다. 밑단이 하의 안에 들어가거나 밖으로 나오는 상태는 요청한 착장 방식 [턱인/턱아웃/원본 유지]을 따른다.

금지:
상의 이외의 제품을 재디자인하지 않는다. 모델의 체형, 팔 위치, 손가락, 자세를 바꾸지 않는다. 임의의 패턴, 장식, 포켓, 단추, 지퍼, 로고와 문자를 추가하지 않는다. 참고사진의 배경과 워터마크를 옮기지 않는다. 불명확한 디테일을 창작하지 않는다.
```
