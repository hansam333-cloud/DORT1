# 하의 교체 전용 프롬프트

대괄호를 실제 제품 정보로 바꿔 사용한다.

```text
Use case: identity-preserve, precise-object-edit
Asset type: 온라인 쇼핑몰 상세페이지용 피팅 사진

입력 이미지:
- 이미지 1: 수정 대상인 원본 피팅 사진
- 이미지 2~N: 교체할 하의 [제품명/SKU]의 [정면/측면/후면/디테일] 참고사진

주요 요청:
이미지 1에서 모델이 착용한 기존 하의만 이미지 2~N의 [제품명] [색상] 하의로 교체한다. 결과는 실제 촬영한 것처럼 사실적이어야 하며, 제품 구조와 핏이 정확하게 보여야 한다.

변경 허용 영역:
하의 본체와 허리, 골반, 엉덩이, 허벅지, 무릎, 종아리, 발목 및 상의·신발과 겹치는 경계만 최소한으로 수정한다. 착용에 필요한 가림, 눌림, 당김, 주름과 접촉 그림자만 조정한다.

제품 재현 기준:
참고사진의 허리선, 밑위, 허리밴드, 여밈, 포켓, 절개, 턱, 다트, 봉제, 바지통 또는 스커트 폭, 총장과 밑단 형태를 유지한다. [소재]의 조직, 두께, 광택, 색상과 움직임을 정확히 표현한다. [핏]의 엉덩이·허벅지 여유와 전체 실루엣을 유지한다.

반드시 유지:
모델의 동일성, 얼굴, 피부색, 체형, 허리·골반 비율, 다리 길이와 두께, 무릎과 발목 위치, 자세와 체중 중심을 유지한다. 상의, 신발, 가방, 액세서리와 배경은 원본 그대로 유지한다. 카메라 시점, 크롭, 조명, 그림자, 색온도, 초점과 사진 질감을 유지한다.

가림과 물리 표현:
허리 부분은 상의의 턱인·턱아웃 상태와 자연스럽게 연결한다. 밑단은 신발과의 앞뒤 관계를 정확히 유지하고 원단 길이와 폭에 맞게 자연스럽게 떨어지게 한다. 다리 사이에 비정상적인 원단 연결이나 불필요한 주름을 만들지 않는다.

금지:
하의에 맞추기 위해 허리, 골반, 엉덩이 또는 다리 체형을 바꾸지 않는다. 다리나 발을 추가·삭제·복제하지 않는다. 상의와 신발을 재디자인하지 않는다. 임의의 포켓, 주름, 턱, 지퍼, 로고와 문자를 추가하지 않는다. 참고사진의 배경과 워터마크를 옮기지 않는다.
```
