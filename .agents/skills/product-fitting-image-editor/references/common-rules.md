# 공통 제작 규칙

## 입력과 실행

- 이미지 1은 수정 대상인 원본 피팅 사진으로 사용한다.
- 이미지 2~N은 교체 제품의 형태, 색상, 소재와 디테일을 확인하는 참고사진으로 사용한다.
- 참고사진의 배경, 모델, 포즈, 촬영 구도, 워터마크와 UI는 결과에 가져오지 않는다.
- 한 번에 상의·하의·신발·가방 중 한 종류와 한 색상만 교체한다.
- 모든 변형은 이전 생성본이 아닌 최초 원본 피팅 사진에서 다시 시작한다.
- 색상별로 별도 생성하고 각 결과를 독립 검수한다.

## 입력 전 확인 정보

- 교체 대상: 상의, 하의, 신발 또는 가방
- 제품명 또는 SKU
- 실제 색상명 또는 승인된 컬러 코드
- 소재와 표면 특성
- 핏
- 반드시 보여야 하는 봉제, 포켓, 스트랩, 버클 등
- 정확한 로고·문자와 위치 또는 없음
- 각 참고 이미지의 정면, 측면, 후면, 45도, 디테일 역할

## 변경 범위

- 지정한 제품과 실제 착용에 필요한 경계만 변경한다.
- 경계에는 피부와 제품의 접촉부, 가림, 눌림, 당김, 자연스러운 주름과 접촉 그림자만 포함한다.
- 비대상 제품, 신체, 배경과 촬영 조건을 변경하지 않는다.
- 편집 범위 밖을 더 보기 좋게 만들기 위한 임의 보정이나 재해석을 하지 않는다.

## 모델과 신체 보존

- 동일성, 얼굴, 피부색, 헤어, 체형, 키 비율, 근육량과 신체 특징을 유지한다.
- 머리, 몸통, 팔, 손, 손가락, 다리, 발과 발가락의 길이·두께·수·방향을 유지한다.
- 자세, 체중 중심, 관절 각도, 손과 발의 위치를 유지한다.
- 제품을 맞추기 위해 몸을 늘이거나 줄이거나 비틀지 않는다.
- 접촉 경계만 최소 조정하고 신체 스펙과 자세는 바꾸지 않는다.

## 제품 일관성

- 실루엣, 패턴 구조, 비율, 절개, 봉제, 여밈, 포켓, 부자재와 마감 위치를 유지한다.
- 색상, 원단 조직, 두께, 광택, 투명도, 탄성과 표면 질감을 참고사진과 일치시킨다.
- 모델과 원근에 맞춰 크기를 조절하되 제품 고유 비율을 바꾸지 않는다.
- 좌우 대칭 구조를 유지하면서 카메라 원근에 맞게 표현한다.
- 보이지 않는 구조는 꾸미지 않고 가장 단순하고 보수적으로 처리한다.
- 로고나 문자는 정확히 판독되고 요청된 경우에만 재현한다. 불명확한 문자나 로고를 만들지 않는다.

## 착용과 물리적 자연스러움

- 제품을 모델의 자세와 중력 방향에 맞게 실제 착용 상태로 표현한다.
- 피부와 의상, 의상과 의상, 손과 가방, 발과 신발의 앞뒤 가림을 정확히 유지한다.
- 제품 무게와 장력에 맞는 눌림, 당김, 주름과 접촉 그림자만 표현한다.
- 소재 두께와 강성에 맞지 않는 주름, 공중에 뜬 부분과 신체 관통을 만들지 않는다.
- 제품 교체 때문에 모델 체형이 달라 보이지 않게 한다.

## 촬영 일관성

- 카메라 위치, 렌즈 원근, 시점, 구도, 크롭, 화면 비율과 캔버스 방향을 유지한다.
- 광원 방향, 밝기, 색온도, 하이라이트, 그림자 농도와 바닥 접지를 유지한다.
- 초점, 심도, 노이즈, 선명도와 사진 질감을 맞춘다.
- 배경, 바닥선, 주변 사물과 여백을 변경하지 않는다.

## 상세페이지 정확성

- 실제 형태, 구성, 색상과 소재에 대한 오해를 만들지 않는다.
- 존재하지 않는 장식, 포켓, 끈, 단추, 지퍼, 버클, 로고와 구성품을 추가하지 않는다.
- 실제 상품 또는 승인된 색상 기준과 사람이 최종 대조한다.
- 참고사진의 워터마크, 쇼핑몰 UI, 화살표, 가격과 설명 문구를 옮기지 않는다.

## 제한과 실패 조건

- 긴팔에서 민소매, 긴 하의에서 짧은 하의, 큰 가방에서 작은 가방처럼 원본에서 가려진 신체나 의상이 새로 드러나는 교체는 정확도가 낮다. 해당 영역이 보이는 별도 원본을 우선한다.
- 제품 정확도가 중요하면 정면·측면·후면·45도·디테일 참고사진을 함께 사용한다.
- 필수 검수 항목이 하나라도 실패하면 상세페이지용으로 승인하지 않는다.

## 파일과 메타데이터

- 임시·원본 생성 파일은 `work`, 최종 결과물은 `outputs`에 둔다.
- 최종 파일명은 한국 표준시 기준 `YY.MM.DD_설명적이름.확장자`를 사용하고 기존 파일을 덮어쓰지 않는다.
- 불투명 상세페이지 이미지는 생성기가 만든 원본 PNG를 `work`에 보존하되 확대된 PNG 중간본을 만들지 않는다. 필요한 크기로 조정하면서 품질 95 JPG로 한 번만 인코딩하고, 정리·검증을 통과한 JPG를 최종본으로 제공한다.
- 투명 배경이 필요한 경우에만 PNG를 최종 형식으로 사용한다.
- 원본 생성 파일을 보존하고 별도 최종본에서 C2PA, PNG `caBX`, JPEG JUMBF와 AI·생성 도구 관련 EXIF/XMP/텍스트 정보를 제거한다.
- ICC 색상 프로파일은 유지한다. 방향을 정상화한 뒤 불필요한 EXIF 방향 정보만 제거한다.
- 제거 후 다시 검사한다. 메타데이터 제거는 플랫폼 자체 판별이나 표시·고지 의무를 없애지 않는다.
- Windows에서는 `prepare_final_jpg.ps1`과 `clean_metadata.ps1`, macOS에서는 Python 3 기반 `prepare_final_jpg.py`와 `clean_metadata.py`를 사용한다.
- 변환·정리 스크립트나 필수 런타임을 실행할 수 없으면 이미지를 폐기하지 않는다. 원본 생성 이미지를 `work`에 복구 가능한 초안으로 보존하고, 처리 완료 전까지 `outputs`의 승인된 최종본으로 취급하지 않는다.
