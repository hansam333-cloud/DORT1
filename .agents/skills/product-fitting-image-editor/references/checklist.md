# 상세페이지 제품 교체 검수표

## 판정

- 통과: 상세페이지에 사용 가능하다.
- 수정: 특정 부분만 다시 편집하면 사용할 수 있다.
- 실패: 모델, 제품 구조 또는 상품 정보가 크게 달라 원본에서 다시 제작해야 한다.
- 필수 항목이 하나라도 실패하면 승인하지 않는다.

## 공통 필수 검수

- 모델 동일성: 얼굴, 피부색, 헤어와 인상이 원본과 같다.
- 신체 스펙: 체형, 키 비율, 근육량, 팔다리 길이와 두께가 같다.
- 자세와 해부학: 자세, 관절 방향, 손발 위치와 손가락·발가락 수가 정상이다.
- 제품 구조: 판매 제품과 실루엣, 구조, 디테일과 구성품이 일치한다.
- 소재와 색상: 승인된 제품 기준과 질감, 두께, 광택과 색상이 일치한다.
- 비대상 영역: 교체 대상 이외의 의상, 액세서리, 신체와 배경이 변하지 않았다.
- 상품 정보: 존재하지 않는 디테일, 구성품, 로고와 문자가 추가되지 않았다.
- 금지 요소: 워터마크, 쇼핑몰 UI, 화살표, 이상한 문자와 중복 물체가 없다.
- 최종 형식: 불투명 이미지는 품질 95 JPG이며 확대된 PNG 중간본이 없다. 투명 배경이 필요한 경우에만 PNG다.
- 메타데이터: 최종본에 C2PA/`caBX`/JUMBF와 AI·생성 도구 식별 정보가 없다.

## 공통 일반 검수

- 가림 관계가 물리적으로 맞다.
- 제품이 뜨거나 신체를 관통하지 않는다.
- 광원 방향, 밝기, 색온도와 접촉 그림자가 원본과 일치한다.
- 제품 크기, 각도와 원근이 모델과 카메라에 맞는다.
- 초점, 선명도, 노이즈와 사진 질감이 원본에 섞인다.
- 화면 비율, 크롭, 방향과 캔버스가 요청 규격과 같다.

## 상의

- 네크라인, 어깨선과 암홀의 형태와 위치가 정확하다.
- 소매 종류, 길이, 폭, 커프스와 좌우 구조가 정확하다.
- 몸판 여유, 총장, 밑단 위치와 핏이 정확하다.
- 절개, 봉제, 여밈, 포켓, 부자재와 로고 위치가 정확하다.
- 원단 두께와 탄성에 맞는 주름이다.
- 목, 겨드랑이, 팔과 손목 경계에 번짐·잘림·관통이 없다.

## 하의

- 허리선, 밑위, 여밈과 허리밴드 구조가 정확하다.
- 골반·허벅지 여유와 실루엣이 정확하며 체형은 유지된다.
- 바지통 또는 스커트 폭, 총장과 밑단이 정확하다.
- 포켓, 턱, 다트, 절개, 봉제와 부자재 수·위치가 정확하다.
- 다리 사이 원단이 붙거나 갈라지거나 비정상적으로 연결되지 않는다.
- 상의와 허리, 신발과 밑단의 가림이 자연스럽다.

## 신발

- 좌우 갑피, 스트랩·끈, 앞코, 뒤축과 밑창 구조가 같다.
- 발 크기·방향과 발가락 수가 정상이고 원본 자세를 유지한다.
- 밑창 두께, 굽 높이, 형태와 소재가 정확하다.
- 스티치, 여밈, 인솔과 부자재 수·위치가 정확하다.
- 발이 인솔과 갑피 안에 자연스럽게 들어가 있다.
- 양쪽 밑창이 바닥에 닿고 접지 그림자가 맞는다.
- 하의 밑단과 신발이 자연스럽게 겹친다.

## 가방

- 실제 치수와 모델 신체를 기준으로 크기와 비율이 맞는다.
- 가로·세로·폭, 바닥, 측면, 입구와 패널 구조가 정확하다.
- 스트랩·손잡이 수, 길이, 폭, 연결 위치와 경로가 정확하다.
- 버클, 지퍼, 포켓, 봉제, 파이핑과 금속 부자재가 정확하다.
- 손가락 수와 자세가 정상이며 손잡이를 자연스럽게 잡는다.
- 스트랩이 신체를 관통하지 않고 무게에 맞는 눌림과 장력이 있다.
- 가방이 중력 방향과 소재에 맞게 형태를 유지한다.

## 작업 기록

- 결과 파일명
- 제품명/SKU
- 교체 대상과 색상
- 원본 파일
- 제품 참고 파일과 각 역할
- 검수일과 검수자
- 시각 검수: 통과, 수정 또는 실패
- 메타데이터 제거: 완료 또는 미완료
- 메타데이터 재검사: 통과 또는 실패
- 최종 형식과 JPG 품질: JPG 95 또는 투명 PNG
- 최종 판정: 통과, 수정 또는 실패

## 최종 승인

- 제품 구조, 색상, 소재, 로고·문자 또는 신체 오류가 없어야 한다.
- 자연스러움보다 실제 제품 정확성을 우선한다.
- 실제 제품 또는 승인된 기준 사진과 사람이 마지막으로 대조한다.
- 최종본은 메타데이터 제거와 재검사를 통과하고 원본 생성 파일과 구분되어야 한다.
- 판매처와 플랫폼의 AI 이미지 표시·고지 정책을 별도로 준수한다.
