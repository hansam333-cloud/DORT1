# 가방 교체 전용 프롬프트

대괄호를 실제 제품 정보로 바꿔 사용한다.

```text
Use case: identity-preserve, precise-object-edit
Asset type: 온라인 쇼핑몰 상세페이지용 피팅 사진

입력 이미지:
- 이미지 1: 수정 대상인 원본 피팅 사진
- 이미지 2~N: 교체할 가방 [제품명/SKU]의 [정면/측면/후면/내부/스트랩/디테일] 참고사진

주요 요청:
이미지 1에서 모델이 착용하거나 들고 있는 기존 가방만 이미지 2~N의 [제품명] [색상] 가방으로 교체한다. 원본의 착용 방식 [숄더/크로스바디/토트/클러치/백팩]을 유지하고 실제 제품의 크기와 구조를 정확히 표현한다.

변경 허용 영역:
가방 본체, 스트랩과 손잡이, 가방에 가려지는 신체·의상의 경계, 손과 손잡이의 접촉부, 어깨나 몸통의 눌림 및 가방의 접촉 그림자만 최소한으로 수정한다.

제품 재현 기준:
참고사진의 가로·세로·폭 비율, 바닥과 측면 구조, 입구, 플랩, 지퍼, 포켓, 패널, 봉제, 파이핑, 손잡이, 스트랩 연결부, 버클과 금속 부자재의 개수 및 위치를 유지한다. [소재]의 결, 두께, 광택, 형태 유지력과 [색상]을 정확히 표현한다. 실제 제품 치수 [가로×세로×폭]를 모델의 신체와 원근에 맞는 크기로 적용한다.

반드시 유지:
모델의 동일성, 얼굴, 피부색, 헤어, 체형, 어깨 너비, 팔과 손의 길이, 손가락 수와 자세를 유지한다. 상의, 하의, 신발, 액세서리와 배경은 원본 그대로 유지한다. 카메라 시점, 크롭, 조명, 그림자, 색온도, 초점과 사진 질감을 유지한다.

가림과 물리 표현:
스트랩은 원본 착용 방식에 맞는 경로로 어깨나 몸통을 따라야 하며 신체나 의상을 관통하지 않아야 한다. 가방의 무게에 맞게 스트랩에 장력이 생기고 어깨·의상에 최소한의 눌림이 표현되어야 한다. 손으로 드는 경우 손가락이 손잡이를 자연스럽게 감싸도록 접촉 경계만 조정하고 손의 위치와 손가락 수는 유지한다. 가방은 중력 방향에 맞게 매달리거나 놓여야 한다.

금지:
가방 크기를 임의로 과장하거나 축소하지 않는다. 스트랩, 손잡이, 버클, 지퍼, 포켓과 금속 부자재를 추가·삭제·복제하지 않는다. 팔과 손의 위치를 크게 바꾸거나 손가락을 변형하지 않는다. 비대상 의상을 재디자인하지 않는다. 임의의 로고와 문자를 추가하지 않고 참고사진의 배경과 워터마크를 옮기지 않는다.
```
