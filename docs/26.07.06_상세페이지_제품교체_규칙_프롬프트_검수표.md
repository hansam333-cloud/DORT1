# 상세페이지 제품 교체 이미지 제작 규칙·프롬프트·검수표

작성일: 2026-07-06
적용 범위: 피팅 사진의 상의, 하의, 신발, 가방 교체
목적: 모델과 촬영 조건은 유지하면서 참고 제품을 정확하고 자연스럽게 착용한 상세페이지 이미지를 제작한다.

## 1. 사용 방법

1. 한 번의 작업에서는 상의·하의·신발·가방 중 한 종류만 교체한다.
2. 아래 전용 프롬프트의 대괄호 항목을 실제 정보로 바꾼다.
3. `이미지 1`은 항상 수정할 원본 피팅 사진으로 지정한다.
4. `이미지 2~N`은 교체할 제품의 참고사진으로 지정하고 각 사진의 방향을 적는다.
5. 생성 결과를 공통 검수표와 해당 제품의 전용 검수표로 확인한다.
6. 수정할 때는 한 번에 한 가지 오류만 지시하고, 중요한 보존 조건을 다시 적는다.
7. 모든 변형은 이전 생성본이 아닌 최초 원본 피팅 사진에서 다시 시작한다.
8. 시각 검수를 통과한 결과는 원본 생성 파일을 보존한 채 별도 최종본으로 복사하고, 최종본에서 AI 관련 메타데이터를 제거한다.
9. 메타데이터 제거 후 파일을 다시 검사하여 C2PA와 생성 도구 식별 정보가 남지 않은 경우에만 `outputs`의 최종 결과물로 사용한다.

### 입력 전 확인할 정보

- 교체 대상: `[상의 / 하의 / 신발 / 가방]`
- 제품명 또는 SKU: `[제품 식별 정보]`
- 실제 색상: `[색상명 또는 확인된 컬러 코드]`
- 소재: `[소재와 표면 특성]`
- 핏: `[슬림 / 레귤러 / 오버핏 등]`
- 반드시 보여야 하는 디테일: `[봉제, 포켓, 스트랩, 버클 등]`
- 로고·문자: `[정확한 표기와 위치 / 없음]`
- 참고 이미지 역할: `[정면 / 측면 / 후면 / 45도 / 디테일]`

## 2. 공통 제작 규칙

### 2.1 입력 이미지 역할

- 이미지 1은 수정 대상인 원본 피팅 사진이다.
- 이미지 2~N은 교체 제품의 형태, 색상, 소재와 디테일을 확인하기 위한 제품 참고사진이다.
- 제품 참고사진의 배경, 모델, 포즈, 촬영 구도와 그림자는 결과 이미지에 가져오지 않는다.

### 2.2 변경 범위

- 지정한 제품 한 종류와 실제 착용에 필요한 경계 부분만 변경한다.
- 경계 부분에는 피부와 제품의 접촉부, 가림, 눌림, 당김, 자연스러운 주름과 접촉 그림자가 포함된다.
- 비대상 제품, 신체, 배경과 촬영 조건은 변경하지 않는다.
- 편집 범위 밖의 요소를 더 보기 좋게 만들기 위한 임의 보정이나 재해석을 하지 않는다.

### 2.3 모델과 신체 보존

- 모델의 동일성, 얼굴, 피부색, 헤어, 체형, 키 비율, 근육량과 신체 특징을 유지한다.
- 머리, 몸통, 팔, 손, 손가락, 다리, 발과 발가락의 길이·두께·수·방향을 유지한다.
- 원본의 자세, 체중 중심, 관절 각도, 손과 발의 위치를 유지한다.
- 제품을 맞추기 위해 모델의 몸을 늘이거나 줄이거나 비틀지 않는다.
- 제품과 접촉하는 신체 경계는 최소한으로 조정하되 신체 스펙과 자세는 바꾸지 않는다.

### 2.4 제품 일관성

- 참고 제품의 실루엣, 패턴 구조, 비율, 절개, 봉제, 여밈, 포켓, 부자재와 마감 위치를 유지한다.
- 색상, 원단 조직, 두께, 광택, 투명도, 탄성, 표면 질감을 참고사진과 일치시킨다.
- 제품 크기는 모델의 신체와 원근에 맞추되 제품 고유의 비율을 바꾸지 않는다.
- 좌우 대칭 제품은 디자인 구조를 동일하게 유지하면서 카메라 원근에 맞게 표현한다.
- 참고사진에서 확인되지 않는 숨은 구조는 임의로 꾸미지 않고 가장 단순하고 보수적으로 처리한다.
- 제품의 로고나 문자는 참고사진에서 정확히 판독되고 사용이 요청된 경우에만 그대로 재현한다. 불명확한 문자나 로고를 새로 만들지 않는다.

### 2.5 착용과 물리적 자연스러움

- 제품은 모델의 자세와 중력 방향에 맞게 실제로 착용된 상태로 표현한다.
- 피부와 의상, 의상과 의상, 손과 가방, 발과 신발 사이의 앞뒤 가림 관계를 정확히 유지한다.
- 접촉 부위에는 제품의 무게와 장력에 맞는 눌림, 당김, 주름과 접촉 그림자를 최소한으로 표현한다.
- 원단의 두께와 강성에 맞지 않는 주름, 공중에 뜬 부분, 신체를 관통하는 부분을 만들지 않는다.
- 제품이 바뀌어도 모델의 체형이 달라 보이지 않도록 한다.

### 2.6 촬영 일관성

- 원본의 카메라 위치, 렌즈 원근, 시점, 구도, 크롭과 화면 비율을 유지한다.
- 원본의 광원 방향, 밝기, 색온도, 하이라이트, 그림자 농도와 바닥 접지감을 유지한다.
- 원본의 초점, 심도, 노이즈, 선명도와 사진 질감을 맞춘다.
- 배경, 바닥선, 주변 사물과 여백을 변경하지 않는다.
- 결과 이미지의 캔버스 크기와 방향을 원본과 동일하게 유지한다.

### 2.7 상세페이지 정확성

- 결과는 제품의 실제 형태, 구성, 색상과 소재에 대한 오해를 만들지 않아야 한다.
- 실제 제품과 다른 장식, 포켓, 끈, 단추, 지퍼, 버클, 로고 또는 구성품을 추가하지 않는다.
- 제품 색상은 모니터상 참고사진만으로 확정하지 말고 실제 상품 또는 승인된 색상 기준과 최종 대조한다.
- 참고사진의 워터마크, 쇼핑몰 UI, 화살표, 배경, 가격과 설명 문구를 결과에 옮기지 않는다.

### 2.8 작업 제한

- 한 번에 여러 제품군을 동시에 교체하지 않는다.
- 생성 결과를 다음 작업의 원본으로 사용하지 않는다. 누적 생성은 모델과 제품의 변형을 키운다.
- 긴팔을 민소매로 바꾸는 것처럼 원본에서 가려진 신체가 새로 드러나는 교체는 정확도가 낮다. 가능하면 해당 신체가 보이는 별도 원본 사진을 사용한다.
- 긴 하의를 짧은 하의로, 큰 가방을 작은 가방으로 바꾸는 경우처럼 가려져 있던 신체나 의상이 드러나는 작업도 같은 기준을 적용한다.
- 제품 정확도가 중요한 경우 정면·측면·후면·45도·디테일 참고사진을 함께 사용한다.

### 2.9 최종 파일의 AI 관련 메타데이터 정리

- 시각 생성이 끝난 뒤 원본 생성 파일은 덮어쓰지 않고 보존하며, 사용자에게 전달할 최종본을 별도로 만든다.
- 최종본에서 C2PA 콘텐츠 자격증명과 PNG `caBX`, JPEG JUMBF 등 생성 이력 블록을 제거한다.
- `OpenAI`, `GPT`, 생성 모델명, 생성 도구명과 작업 이력이 들어 있는 EXIF·XMP·텍스트 메타데이터를 제거한다.
- 색상 정확도에 필요한 ICC 프로파일은 AI 관련 정보가 아니므로 유지한다. 방향 정보가 필요한 파일은 픽셀 방향을 먼저 정상화한 뒤 불필요한 EXIF를 제거한다.
- PNG는 이미지 픽셀 데이터와 투명도를 바꾸지 않는 방식으로 메타데이터만 정리한다. JPEG는 불필요한 재압축과 화질 저하가 생기지 않는 방식을 우선한다.
- 제거 후 메타데이터를 다시 검사하여 C2PA/`caBX`/JUMBF와 AI 생성 도구 식별 정보가 없는지 확인한다.
- 메타데이터 제거는 플랫폼의 자체 AI 판별 가능성이나 판매처의 AI 이미지 표시·고지 의무를 없애지 않는다.

## 3. 상의 교체 전용 프롬프트

```text
Use case: identity-preserve, precise-object-edit
Asset type: 온라인 쇼핑몰 상세페이지용 피팅 사진

입력 이미지:
- 이미지 1: 수정 대상인 원본 피팅 사진
- 이미지 2~N: 교체할 상의 [제품명/SKU]의 [정면/측면/후면/디테일] 참고사진

주요 요청:
이미지 1에서 모델이 착용한 기존 상의만 이미지 2~N의 [제품명] [색상] 상의로 교체한다. 결과는 실제 촬영한 것처럼 사실적이어야 하며, 제품 정보가 정확하게 보여야 한다.

변경 허용 영역:
상의 본체와 상의가 닿는 목, 어깨, 겨드랑이, 팔, 손목, 허리 및 다른 의상과 겹치는 경계만 최소한으로 수정한다. 제품 착용에 필요한 가림, 눌림, 당김, 주름과 접촉 그림자만 조정한다.

제품 재현 기준:
참고사진의 네크라인, 어깨선, 암홀, 소매 형태와 길이, 가슴·허리 여유, 총장, 밑단, 절개, 봉제, 여밈, 포켓, 부자재와 로고 위치를 유지한다. [소재]의 조직, 두께, 광택, 탄성, 색상과 드레이프를 정확히 표현한다. 제품 고유의 [핏]과 실루엣을 유지하되 모델의 기존 신체 비율에 자연스럽게 맞춘다.

반드시 유지:
모델의 동일성, 얼굴, 피부색, 헤어, 체형, 어깨 너비, 가슴과 허리 비율, 팔 길이와 두께, 자세를 유지한다. 하의, 신발, 가방, 액세서리와 배경은 원본 그대로 유지한다. 카메라 시점, 크롭, 조명, 그림자, 색온도, 초점과 사진 질감을 유지한다.

가림과 물리 표현:
상의와 피부, 상의와 하의, 상의와 가방 또는 액세서리의 앞뒤 관계를 원본 포즈에 맞게 표현한다. 원단 두께와 중력에 맞는 주름만 만들고, 신체를 관통하거나 공중에 뜬 옷을 만들지 않는다. 밑단이 하의 안에 들어가거나 밖으로 나오는 상태는 요청한 착장 방식 [턱인/턱아웃/원본 유지]을 따른다.

금지:
상의 이외의 제품을 재디자인하지 않는다. 모델의 체형, 팔 위치, 손가락, 자세를 바꾸지 않는다. 임의의 패턴, 장식, 포켓, 단추, 지퍼, 로고와 문자를 추가하지 않는다. 참고사진의 배경과 워터마크를 옮기지 않는다. 불명확한 디테일을 창작하지 않는다.

필수 후처리(생성 완료 후 시스템 작업):
시각 검수를 통과한 결과는 원본 생성 파일을 덮어쓰지 않고 별도 최종본으로 저장한다. 최종본에서 C2PA, PNG caBX, JPEG JUMBF와 OpenAI·GPT·생성 모델·생성 도구 관련 메타데이터를 제거한다. 이미지 픽셀, 색상, ICC 프로파일, 화면 비율과 해상도는 유지한다. 제거 후 재검사하여 AI 관련 메타데이터가 남지 않은 경우에만 최종본으로 승인한다.
```

Use case: identity-preserve, precise-object-edit
Asset type: 온라인 쇼핑몰 상세페이지용 피팅 사진

입력 이미지:
- 이미지 1: 수정 대상인 원본 피팅 사진
- 이미지 2~N: 교체할 하의 [제품명/SKU]의 [정면/측면/후면/디테일] 참고사진

이미지 1에서 모델이 착용한 기존 하의만 이미지 2~N의 [제품명] [색상] 하의로 교체한다. 결과는 실제 촬영한 것처럼 사실적이어야 하며, 제품 구조와 핏이 정확하게 보여야 한다.

제품 재현 기준:
참고사진의 허리선, 밑위, 허리밴드, 여밈, 포켓, 절개, 턱, 다트, 봉제, 바지통 또는 스커트 폭, 총장과 밑단 형태를 유지한다. [소재]의 조직, 두께, 광택, 색상과 움직임을 정확히 표현한다. [핏]의 엉덩이·허벅지 여유와 전체 실루엣을 유지한다.

반드시 유지:

가림과 물리 표현:

## 7. 검수 진행 방법

## 13. 최종 승인 원칙

- 필수 항목은 모두 통과해야 한다.
- 제품 구조, 색상, 소재, 로고·문자 또는 신체에 오류가 있으면 상세페이지용으로 승인하지 않는다.
- 자연스럽지만 실제 제품과 다른 결과보다, 연출이 다소 단순해도 실제 제품에 충실한 결과를 우선한다.
- AI 결과는 최종 상품 정보가 아니다. 실제 제품 또는 승인된 기준 사진과 사람이 마지막으로 대조한다.
- 승인되지 않은 참고사진이나 워터마크가 포함된 자료는 제품 확인용으로만 사용하고 결과에 해당 요소를 재현하지 않는다.
- 최종 결과물은 AI 관련 메타데이터 제거와 재검사를 통과해야 하며, 원본 생성 파일과 구분하여 저장한다.
- 메타데이터가 제거되었더라도 판매처와 플랫폼의 AI 이미지 표시·고지 정책은 별도로 확인하고 준수한다.
